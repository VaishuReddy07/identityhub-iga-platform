# IdentityHub roadmap

## Implemented in the runnable foundation

- Keycloak realm and development users
- OAuth 2.0 / OIDC browser login
- SSO-ready React clients
- Spring Security JWT validation
- Realm-role mapping to Spring authorities
- PostgreSQL audit storage
- OpenLDAP local directory
- Python Keycloak provisioning lab
- Docker Compose environment

## Next implementation steps

1. Configure LDAP federation in Keycloak and test directory login.
2. Configure TOTP MFA in Keycloak.
3. Add application/client registration APIs.
4. Add user lifecycle and deprovisioning flows.
5. Add SAML 2.0 and WS-Federation test labs.
6. Add API/integration/security tests.
7. Add Prometheus/OpenTelemetry metrics and traces.
8. Add CI/CD and container security checks.
9. Add Kubernetes/Helm deployment.
10. Document threat model and operational runbooks.
